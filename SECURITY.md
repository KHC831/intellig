# Security Policy

## Supported Versions

Only the most recent minor release is supported. Older versions
receive no security backports — upgrade to the latest 0.x minor (or
later) before reporting a vulnerability.

## Reporting a Vulnerability

Please report security vulnerabilities privately to kachan831@gmail.com.
Do not file public GitHub issues for security bugs — public disclosure
of an unpatched vulnerability puts every IntelliG user at risk.

We aim to acknowledge a private report within 7 days. Once a report
is verified, we aim to ship a fix within 14 days of acknowledgment
in the next patch release. Coordinated-disclosure timelines are
negotiable for severe issues — reach out and we'll work with you on
a window that balances user safety against responsible-disclosure
norms.
